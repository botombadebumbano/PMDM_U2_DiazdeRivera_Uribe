# Enrutamiento Avanzado

Proyecto Android desarrollado con Java y Android Navigation.

## Abrir el proyecto

1. Descomprime el repositorio.
2. Abre en Android Studio la carpeta raíz `EnrutamientoAvanzado` (la que contiene `settings.gradle.kts`).
3. Espera a que Gradle termine la sincronización.
4. Ejecuta la configuración `app` en un emulador o dispositivo Android.

## Configuración del proyecto

- Lenguaje: Java.
- Android Gradle Plugin: 9.0.1.
- Gradle Wrapper: 9.1.0.
- `compileSdk` / `targetSdk`: 36.
- `minSdk`: 24.
- Navegación: AndroidX Navigation con Safe Args.
- Identificador de aplicación: `com.ejemplo.enrutamientoavanzado`.

El proyecto incluye el Gradle Wrapper (`gradlew`, `gradlew.bat` y `gradle/wrapper`). No incluye archivos locales de configuración, cachés ni carpetas de compilación; Android Studio/Gradle los generará al abrirlo.
