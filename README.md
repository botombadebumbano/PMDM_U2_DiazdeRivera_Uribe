📱 Descripción de las Prácticas

1_EnrutamientoAvanzado: Aplicación enfocada en la navegación moderna en Android utilizando Fragmentos, componente Navigation, paso seguro de argumentos con SafeArgs y configuración de deep links.

2_MisTareas: Gestor de tareas que implementa listas dinámicas mediante RecyclerView, Adapter y ViewHolder personalizados, además de la gestión de menús (opciones, contextual y popup).

3_MisTareas2: Evolución de la aplicación anterior que incorpora persistencia de configuración con SharedPreferences, diálogos interactivos (AlertDialog, DatePicker) y notificaciones en pantalla mediante Toast y Snackbar.

4_MiBiblioteca: Aplicación de gestión de libros con persistencia local estructurada mediante la librería Room (Entidad, DAO y Base de Datos) y ejecución de operaciones en segundo plano mediante hilos.

5_NoticiasFP: Lector de noticias diseñado bajo las guías de Material Design 3, integrando temas personalizados (modo claro y oscuro), MaterialToolbar, panel lateral (DrawerLayout y NavigationView), tarjetas (CardView), etiquetas (Chip) y botón de acción flotante extendido (ExtendedFloatingActionButton).
